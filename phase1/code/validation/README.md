# Project Review Scripts

This folder holds review and validation scripts that inform extract filters.
These scripts are additive and do not replace deliverable code.

Suggested workflow:
1. Run `python code/extract/extract_data.py --mode analysis`
2. Run review scripts in this folder to validate and refine filters
3. Update files in `notes/` (e.g., keep lists, exclusion terms)
4. Re-run extract

Note: Existing deliverable scripts remain in `code/deliverable01/`.
