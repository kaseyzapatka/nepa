# Manual Corrections Workflow

## Scripts (`code/manual_training/`)

| Script | Purpose |
|---|---|
| `01_find_ce_initiation_candidates.py` | Queries the regex cache, anchors on known BERT decision dates, finds candidate dates that fall before them — exports to a review CSV |
| `02_apply_corrections.py` | Reads any filled-in review CSV, deduplicates against existing corrections, appends to the master corrections file |
| `03_build_gold_standard_sample.py` | Builds held-out evaluation set — not part of the correction loop |

## Data Files

| File | Role |
|---|---|
| `data/manual_training/review_ce_initiation_candidates.csv` | **You fill this in.** Generated by `01_find_...`, set `correct_type` per row, then run `02_apply_corrections.py` to consume |
| `data/analysis/manual_training_corrections.csv` | Master corrections file. `--bert-generate` reads this and overrides weak labels for matching `(project_id, date)` pairs |

## Flow

```
01_find_ce_initiation_candidates.py
        ↓
data/manual_training/review_ce_initiation_candidates.csv   ← you edit this
        ↓
02_apply_corrections.py
        ↓
data/analysis/manual_training_corrections.csv              ← master file
        ↓
--bert-generate  (corrections override weak labels here)
        ↓
--bert-train --source CE
```
