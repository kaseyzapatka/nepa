# D4 Candidate Labeling — Active-Learning Round 2 (200 rows)

You are labeling timeline date candidates extracted from NEPA review documents.
Each candidate is a specific date pulled from a document. Your job is to decide
what the [[marked date]] represents.

## Output format
Return a **self-contained Python script** named `apply_labels_al2.py` that merges
your labels directly into `labeling_sample.csv`. The user will run it from the repo
root with `python phase2/output/deliverable04/apply_labels_al2.py`.

The script must:
1. Define `LABELS` — a list of 200 dicts, one per candidate, in the same order as
   the input, each with three keys:
     - `candidate_id` — copy exactly as given
     - `label` — one of: `initiation` | `decision` | `neither`
     - `notes` — one sentence: the rule that applies + a short direct quote from the
       context excerpt that clinched the decision (≤ 20 words from the excerpt, in quotes).
       Example: `"Scoping started: 'scoping letter was sent to cooperating agencies on this date'"`
2. Load `phase2/output/deliverable04/labeling_sample.csv`
3. Merge `label` and `notes` from `LABELS` into the loaded DataFrame on `candidate_id`
4. Write the result back to the same path (overwrite in place)
5. Print a confirmation: `"Applied N labels to labeling_sample.csv"`

The script must be fully self-contained (imports only `pandas`). No other output.

Valid labels: `initiation` | `decision` | `neither`

---

## Labeling rules

**`initiation`** — the NEPA process started:
- NOI published in the Federal Register ("NOI was published … which initiated the scoping period")
- Application / SF-299 / ROW / permit filed or received ("BLM received an application")
- Scoping started: "opened a 30-day scoping period", "scoping letter was sent", "external scoping notices sent out"
- FERC "approved entry to the pre-filing process"
- DOE Initiator signature (program office initiating the CX — distinct from the NEPA Compliance Officer)
- "Posted to the NEPA Register / ePlanning website"

**`decision`** — the agency decided:
- NEPA Compliance Officer signature / "Date Determined" (when it is the operative determination)
- Field Manager / Field Office Manager / authorizing-official authorization signature
- "It is my decision …", Decision Record date, FONSI cover month, "DOE issued a FONSI on"
- ROW grant issued; BLM CX form "Date:" header and CX/Decision-Record cover months
- USACE permit decision / appeal-options notification

**`neither`** — everything else:
- Specialist/reviewer signatures (wildlife, cultural, realty, biology, NEPA-coordinator)
- SHPO/USFWS/tribal consultation dates (Section 106, ESA): concurrences, responses, meetings, BA submissions
- Comment-period end dates, protest/objection-period end dates, Draft EA/EIS release (mid-process)
- EA/EIS/DEIS/FEIS document cover months (the decision is the FONSI/ROD, not the analysis doc)
- NEPA case numbers parsed as dates; bibliographic / Federal Register citations; map/figure/drawing dates
- Permit term/expiration dates, prior grants/leases/RODs (historical), survey/inspection/field-visit dates

**Tie-breakers:**
- A CX document cover month → `decision` (the CX IS the determination)
- An EA/EIS document cover month → `neither` (the decision is the separate FONSI/ROD)
- Label only the `[[marked]]` date; ignore other dates in the window
- A survey/meeting/inspection conducted "on" a date is `neither`, even next to a milestone

**Key reminder:** The `candidate_role` column shows the regex system's *guess* — it is
often wrong. Ignore it and label purely from the `[[marked date]]` in the context excerpt.
