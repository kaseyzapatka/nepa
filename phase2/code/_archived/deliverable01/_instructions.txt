Please build a small example bank of text chunks to help calibrate NEPA trigger classification.

Goal:
Collect representative examples of:
- true trigger evidence
- ambiguous / boundary-case evidence
- false-positive boilerplate or non-evidence

Targets:
- 3-5 clean positive examples per class
- 5-10 examples for the biggest ambiguous rule families
- 10+ hard negatives

Positive classes:
- federal_funding
- federal_action
- federal_land
- federal_permit
- federal_program
- federal_property_transaction

Highest-priority ambiguous rule families:
- T1a_DOE_action
- T1a_DOE_funding
- T3_sec404
- T3_arra
- T1b_arra
- T1a_BLM_land
- T1a_BLM_action
- T3_rmp

For each example, save:
- Rule family
- Project ID
- Suggested class
- Why
- Chunk

If using a spreadsheet, these are the preferred columns:
- example_type
- rule_family
- project_id
- suggested_class
- why
- chunk

How to label examples:
- positive: the text clearly supports the class
- boundary: the text could plausibly support more than one class
- negative: the text looks relevant but should not drive classification

Selection rules:
- save short exact chunks, not full documents
- keep the actual trigger phrase in the chunk
- do not paraphrase the chunk text
- in “Why,” explain why the chunk is evidence or non-evidence
- prefer project-specific, affirmative language for positive examples
- prefer realistic false-positive traps for negatives

Priority order:
1. DOE funding vs action boundary cases
2. Section 404 positives and negatives
3. ARRA positives and negatives
4. BLM land vs action
5. RMP / programmatic cases

Good negatives include:
- CE checklist boilerplate
- legal/compliance lists
- generic Section 404 mentions that are not project-specific triggers
- generic ARRA mentions without a funding nexus
- plan-conformance text that is not a true programmatic action

Done criteria:
- each positive class has 3-5 strong examples
- the major ambiguous rule families have 5-10 examples total
- there are at least 10 hard negatives
- each saved chunk is clear enough that someone else can understand why it was labeled that way
